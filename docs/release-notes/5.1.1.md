# 5.1.1 릴리즈 노트

스토어에 올라가는 짧은 문안은 저장소 최상단 `RELEASE_NOTES.md` 의 `## 5.1.1` 절이다.
DeployBar 가 배포할 때 읽어 가는 것은 **그 파일 하나뿐**이므로, 문구를 고칠 일이 있으면
거기서 고친다. 이 문서는 무엇을 왜 고쳤는지의 기록과 심사·배포 메모다.

(앱 안 변경 이력은 `ChangelogView.swift` 의 `5.1.1` 항목)

⚠️ 5.1.0 은 빌드 12로 제출했다. 이 판의 문안은 그 뒤에 고친 것만 담는다.

## 이번에 고친 것

### 하나. 설정이 한 화면에 서른 줄이었다

여섯 섹션의 행이 한 화면에 이어져 있어서, 찾는 줄이 어느 섹션에 있는지 모르면 끝까지
내려 봐야 했다. 첫 화면에는 갈래 이름만 세웠다(키보드 · 단축어 · 화면과 표시 ·
내 데이터 · 도움말과 문의 · 앱 정보). 행은 갈래마다 한 칸 안쪽 화면으로 옮겼다
(`*SettingsView.swift`). 안쪽 화면도 첫 화면과 같은 바탕을 쓴다(`settingsCategoryChrome`).

피드백 보내기 · 리뷰 남기기는 "도움말과 문의" 안에 두면 거의 안 열린다. 첫 화면 맨 아래에
따로 세웠다. 같은 곳으로 가는 문이 둘이 되지 않게 안쪽에서는 뺐다.

### 둘. 앱을 켤 때 단축어가 위에서 내려왔다

녹화로 원인을 하나씩 잡았다. 전부 "첫 프레임 뒤에 무언가가 늦게 도착한다" 는 같은 모양이었다.

- **단축어를 늦게 읽었다.** 목록의 `.task` 에서 처음 읽어서, 첫 몇 프레임은 빈 페이지(스크롤뷰
  없음)가 그려지고 그 뒤 격자로 갈렸다. 네비게이션 바가 새로 생긴 스크롤뷰를 잡으며 큰 제목이
  접혔다 펼쳐졌고, 그 사이 카드가 통째로 위로 튀었다가 0.2초쯤 140pt 미끄러져 내려왔다.
  뷰모델 init 에서 읽는다.
- **제목 모드를 등장 직후에 바꿨다.** `.large` 로 시작해 0.15초 뒤 `.inlineLarge` 로 바꾸던
  것을 처음부터 `.inlineLarge` 로 둔다. 바꾸는 순간 제목이 접혔다 펼쳐졌다.
- **팁·배너가 끼어들 때 오프셋 출렁임을 스크롤로 읽었다.** 제목 접기는 이제 손이 굴린
  동안(`onScrollPhaseChange`)만 스크롤을 따라간다.
- **제안 카드가 격자 맨 앞에 늦게 끼어들었다.** 모든 카드가 한 칸씩 밀렸다. 첫 프레임 전에
  자리를 정한다.
- **팁이 끼어들 때 아래 카드가 툭 밀렸다.** 팁 상태를 애니메이션 안에서 바꿔 카드도 같은
  곡선으로 내려간다(`AnimatedTip`).
- **런치 화면이 흰색이었다.** 앱 바탕은 회색이라 켤 때 흰 화면이 번쩍였다. 런치 화면 바탕을
  앱 바탕색으로 맞췄다(`LaunchBackground`, 다크 포함).
- **켜고 1초 뒤 "새로운 배경을 써보시겠어요?" 판이 덮였다.** 켠 그 화면에서는 묻지 않고,
  다른 탭에 다녀와 목록으로 돌아온 때 묻는다.

### 셋. 키보드 미리보기에서 키와 화면이 따로 올라왔다

`KeyboardView` 가 키 목록을 빈 채로 시작해 `onAppear` 에서 채웠다. 무대가 아래에서 올라오는
도중에 빈 화면이 격자로 갈리면서, 키만 제자리에 먼저 나타나고 머리말·입력창은 아직 올라오는
중이었다(녹화에서 키가 첫 프레임부터 최종 위치에 서 있었다). 키를 **만들 때부터** 채운다.
익스텐션도 같은 뷰라 onAppear 의 다시 읽기는 그대로 둔다.

내려갈 때는 `easeIn` 이라 최고 속도로 화면 끝에 부딪혀 툭 끊겼다. `easeInOut` 으로 바꿨다.

### 넷. 갈래를 넘기면 마지막 갈래로 튀었다

경계 순환(첫 갈래에서 오른쪽 → 마지막 갈래)을 **손을 뗄 때의** 갈래로 판단했다. 즐겨찾기에서
기본으로 넘기면 손을 뗄 때는 이미 기본이라 "첫 갈래에서 오른쪽으로 민 것" 으로 읽혀, 멀쩡히
도착한 기본을 두고 마지막 갈래로 튀었다. 스와이프를 **시작한 순간**의 갈래로 판단한다.

### 다섯. 작은 것들

- 키보드 미리보기 입력창의 캐럿이 깜빡인다. 글이 바뀐 직후에는 켠 채로 둔다. 칸을 누르면
  "여기에 입력돼요" 가 비켜서고 캐럿만 남는다.
- Pro 활성화됨을 누르면 "내 Pro 혜택" 화면이 열린다. 무료 한도와 지금 쓰는 양을 나란히
  세우고 넘어선 만큼을 짚는다. 단축어 개수는 저장 관문과 같은 셈법(`ownMemoCount`)이다.
- 키 격자 위 여백을 12pt 에서 4pt 로 줄였다. 첫 줄 물결이 잘리지 않게 자르는 선만 위로
  올렸다(`TopBleedClip`). 앱과 익스텐션이 같이 바뀐다.
- 함께 쓰는 앱에 실제 앱 아이콘이 선다(LeeoKit 3.8.0). 각 앱 레포의 AppIcon 원본을 LeeoKit
  에 상수로 박았다(`scripts/embed_family_icons.py`).

## 심사·배포 메모 (내부)

### ⚠️ 실기기 확인

시뮬레이터 녹화로 본 것: 켤 때 흔들림 없음, 런치 화면 색, 무대가 한 덩어리로 올라옴,
즐겨찾기 → 기본 스와이프, 캐럿 깜빡임, 키 격자 여백. 아래는 **녹화로 못 본 것**이다.

1. 키보드 미리보기 입력창을 눌러 "여기에 입력돼요" 가 사라지는지.
2. 무대가 **내려갈 때** 끝이 부드러운지.
3. 설정 첫 화면: 갈래 여섯 줄, 맨 아래 피드백 보내기 · 리뷰 남기기.
4. Pro 사용자로 설정 > Pro 활성화됨 → 내 Pro 혜택의 숫자가 맞는지.
5. 설정 > 앱 정보 > 함께 쓰는 앱에 실제 아이콘이 서는지.
6. 튜토리얼 중 키 첫 줄 물결이 위에서 잘리지 않는지, 키를 굴릴 때 버튼 줄을 덮지 않는지.
7. 앱을 켠 뒤 다른 탭에 다녀왔을 때만 배경 제안 판이 뜨는지(조건이 맞는 사용자).
